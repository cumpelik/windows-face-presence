Notes
-----
* The libraries marked "(in OpenCV)" / "(in runtime)" are statically linked into
  OpenCvSharpExtern.dll by the OpenCvSharp4.runtime.win package. Face Presence
  only uses the OpenCV core, imgproc, imgcodecs, objdetect and dnn modules; OCR,
  video I/O and the other bundled code paths are never called.
* The FFmpeg video I/O plugin (opencv_videoio_ffmpeg, LGPL) shipped in the same
  package is deliberately excluded from the Face Presence build.
* The .NET runtime is not bundled; the EXE requires the .NET 8 Desktop Runtime.
* WPF UI embeds the Fluent UI System Icons fonts (Regular and Filled) used for the icons.
* The face models are the unmodified ONNX files from the OpenCV Zoo:
  - YuNet: Wu, W., Peng, H., Yu, S. "YuNet: A Tiny Millisecond-level Face
    Detector." Machine Intelligence Research 20(5), 656-665 (2023).
  - SFace: Zhong, Y. et al. "SFace: Sigmoid-Constrained Hypersphere Loss for
    Robust Face Recognition." IEEE TIP (2021), arXiv:2205.12010.
    ONNX conversion by Chengrui Wang.
